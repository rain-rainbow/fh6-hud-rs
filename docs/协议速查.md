# FH6 数据包格式速查表

> 本文件是 [`crates/fh6-core/src/pack.rs`](../crates/fh6-core/src/pack.rs) 的
> 「人类可读版」。常量与偏移量以代码为准，本表用于快速查阅与复核。

## 可信度分级

| 标记 | 含义 |
|---|---|
| ✅ 官方 | 官方文档直接给出（类型、顺序、包长、回环支持） |
| 🔶 逆向 | 官方**未给偏移表**，由多份独立实现 + 实际抓包交叉验证 |
| ⚠️ 存疑 | 官方与实现矛盾，或仅单一来源 |

> **重要**：官方 FH6「数据输出」文档只列出 88 个字段的**类型与顺序**，
> **没有给出任何字节偏移**。下表所有偏移量均属 🔶 逆向结论。

## 包总览

| 项目 | 值 |
|---|---|
| 官方声明包长 | **324 字节** |
| 88 个字段按类型尺寸求和 | **323 字节** |
| 差值 | **1 字节 = C 结构体尾部对齐填充** |
| 字节序 | 小端（官方未写明，靠实现一致 + 抓包确认） |
| 发送时机 | 仅在**实际驾驶中**发送；菜单、暂停、回放、倒带、赛后都不发 |
| 发送频率 | 官方只说 `at a rate equal to the game's frame rate`，**未给 Hz** |
| 目标数量 | **单一**目标地址（官方：`A single packet format is sent to the configured address`） |
| 回环支持 | ✅ 官方两次明确 `127.0.0.1` 受支持 |
| 包格式设置项 | **不存在**。官方：`The packet format is fixed. Unlike Forza Motorsport, there is no option to select between different formats.` |

### 关于 323 vs 324 —— 本项目实测确认的结论

结构体含 `f32` / `i32` / `u32`（对齐要求 4 字节），因此 `sizeof` 必须是 4 的倍数。
323 向上取整 = **324**。

**第 324 字节就是编译器的对齐填充，不是任何字段。** 这解释了官方那句
`Total packet size: 324 bytes.` 的由来，也与「抓包中该字节恒为 0」完全自洽。

验证代码：`crates/fh6-core/src/lib.rs` 中的测试
`结构体大小必须等于官方声明的324字节`。

## 与 Forza Motorsport / FH4 / FH5 的关系

* 官方 FH6 文档**全文未提及 FH5**，其对比基准是 **Forza Motorsport**。
* FH6 与 FH5 包**总长相同（324 字节）**，差异只在 offset **232–244**：
  FH6 给 FH5 中未文档化的「12 字节空洞」赋予了 3 个语义字段。
  ⚠️ 这是**抓包结论，非官方表述**。
* 实务影响：**FH5 解析器能"不报错地"读 FH6 包**（位置/速度/圈速/输入偏移
  完全一致），但会**静默丢弃**这 3 个字段。
* 「Sled（232 字节）/ Dash（311 字节）」这套术语出自 **Forza Motorsport**
  官方文档。用它们描述 FH6 属于借用词汇 —— FH6 只有一种固定格式。
